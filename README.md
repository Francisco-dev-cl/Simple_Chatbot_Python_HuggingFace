# Simple Chatbot with Python and Hugging Face

This repository contains a practical project focused on creating a foundational conversational interface using open-source Large Language Models (LLMs) with Python and Hugging Face.

## 🎯 Project Objective

The goal of this project is to implement a straightforward, functional command-line chatbot that interfaces with generative language models via Hugging Face pipelines, serving as an entry point for building text-generation workflows.

## 📁 Repository Structure

* **`chatbot.py`**: The core execution script that initializes the language model pipeline, handles user console prompts, and structures text generation.
* **`my_env/`**: Dedicated local virtual environment folder isolating project-specific dependencies.

## 🛠 Technologies Used

* **Language:** Python 3.x
* **AI/ML Libraries:** Hugging Face Transformers
* **Environment:** Python virtual environments (`venv`)

## 🚀 Installation and Execution

### 1. Clone the repository

```bash
git clone https://github.com
cd Simple_Chatbot_Python_HuggingFace
```

### 2. Activate the virtual environment

```bash
source my_env/bin/activate  # On macOS/Linux
# OR
my_env\Scripts\activate     # On Windows
```

### 3. Run the chatbot

```bash
python chatbot.py
```

## 📈 Demonstrated Skills

* **LLM Pipeline Integration:** Practical application of Hugging Face wrappers for loading conversational text-generation architectures.
* **Console-Based UX:** Structuring interactive text feedback loops between user inputs and raw model inferences.
* **Environment Management:** Maintaining strict isolation profiles for specialized machine learning configurations.
